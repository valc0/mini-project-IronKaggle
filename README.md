# king_ country_ houses_aa

### About Dataset

In this dataset we have to predict the sales price of houses in King County, Seattle. It includes homes sold between May 2014 and May 2015. Before doing anything we should first know about the dataset what it contains what are its features and what is the structure of data.

The dataset cantains 20 house features plus the price, along with 21613 observations.

The description for the 20 features is given below:

| Feature | Description |
| :--- | :--- |
| `id` | Unique numeric identifier assigned to each house being sold. |
| `date` | The date on which the house was sold. |
| `price` | The sale price of the house (Target Variable). |
| `bedrooms` | Number of bedrooms in the house. |
| `bathrooms` | Number of bathrooms in the house. |
| `sqft_living` | Measurement of the house interior living space in sq ft. |
| `sqft_lot` | Measurement of the land lot in sq ft. |
| `floors` | Total number of floors (levels) in the house. |
| `waterfront` | Dummy variable indicating whether the house has a waterfront view (0 = No, 1 = Yes). |
| `view` | An index from 0 to 4 of how good the view from the property was. |
| `condition` | Overall condition of the house on a scale of 1 to 5. |
| `grade` | Overall grade given to the housing unit, based on the King County grading system (1 to 11). |
| `sqft_above` | Measurement of the house space above ground level in sq ft (excludes basement). |
| `sqft_basement` | Measurement of the basement space in sq ft. |
| `yr_built` | The year the house was originally built. |
| `yr_renovated` | The year of the house's last renovation (0 if never renovated). |
| `zipcode` | The zipcode area of the house. |
| `lat` | Latitude coordinate. |
| `long` | Longitude coordinate. |
| `sqft_living15` | Living room area in 2015 in sq ft (implies some renovations). |
| `sqft_lot15` | Lot size area in 2015 in sq ft (implies some renovations). |
